# 当 Agent 卖 $120 一个月，我选择自己造

> 全文约1489字，阅读需4分钟

这个十月，AI Agent 圈热闹得很。Meta 给 Muse 配了智能眼镜，又掏出一个钥匙扣大小的随身硬件；Grok Bot 的企业版挂出 120 美元一座每月的价签；Instinct 成立几周，估值破百亿。

锣鼓声里，我的 Agent 刚帮我发完这个月的第三篇公众号文章。它顺带把博客也部署了，封面也传了，最后回我一句：HTTP 200，验证通过。

这个月的全部成本，一杯奶茶钱。

## 先上账单

先交代家底。我的个人 Agent 全家桶，八个组件：

| 组件 | 选型 | 干什么 |
|---|---|---|
| Agent | Hermes（开源） | 对话、定时任务、技能系统 |
| 记忆 | Hindsight（自托管） | 跨会话记住我的偏好 |
| 组网 | EasyTier（开源） | VPS、NAS、Windows 三机组内网 |
| 文件同步 | Syncthing（开源） | 跨设备文件实时同步 |
| 笔记 | Obsidian | 本地 Markdown，数据在我手里 |
| 加密 | Cryptomator | 文件加密后再上云 |
| 系统 | Ubuntu 22.04 | 一台 2 核的 VPS |
| 入口 | 飞书 + 微信 | 免费，走到哪聊到哪 |

八件里七件开源，剩下一件 Obsidian 对个人也免费。真正的开销只有两项：VPS 租金，模型订阅。对比一下：Muse 订阅 20 到 100 美元一个月，Grok Bot 企业版一座 120 美元——我这大概相当于请了一个不走的实习生，全年无休，还不要五险一金。

## 三个"懂我"的瞬间

账单是死的，好用是活的。说三个真实发生的瞬间。

**瞬间一：接力。**

前几天写 NeoPad 的更新文章，Windows 端的 AI 写完稿、做好封面，文件落进收件箱。几分钟后，VPS 上的 Hermes 接手：质检、补 frontmatter、发公众号草稿箱、构建博客、推送 GitHub，最后把成品挪进归档区，汇报"HTTP 200，验证通过"。全程我没碰一次文件。

两台机器接力的跑道，是我自己攒的一套 AgentFS——专门给 AI 用的文件系统。目录就是岗位：inbox 收新活，output 放产出，archive 存档，技能库挂在一旁随取随用；Syncthing 负责把这套目录实时搬上三台机器。墙上还贴着一份 AGENTS.md 规章：哪类文件自动流转、哪些区域谁都不许动、新来的 AI 进门先读规则再干活。不同任务各有专属工作区，井水不犯河水。

这套东西没有一行程序代码，全是现成开源件加纯文本规则。但把文件系统当成 Agent 的办公场所来设计——收件箱、产出区、规章制度——目前还真没见几个人做。为什么选文件当骨架？因为文件是最老牌的通用接口：不管哪家的 AI，Windows 的还是 Linux 的，今天发布的还是明年发布的，拿到一个纯文本文件都会读。模型会过时，协议会改版，文件夹不会。算是我给这场开源运动交的一点作业。

**瞬间二：记得。**

它记得我公众号文章的篇幅习惯，开头要有阅读提示行；记得上一篇引了辛弃疾，这一篇就得换一本书，免得审美疲劳；记得发布流程里每一步的细节，渲染用哪个主题，封面放哪个目录。

这些都不是内置功能，是半年来一次次对话攒下来的。坦白讲，它也闹过笑话——连自己用的什么模型都答错过一回。但记忆这东西，攒一笔是一笔，用得越久越顺手。这话说出来像广告词，这次是真实体验。

**瞬间三：主动。**

每天晚上十点，Blogwatcher 准时扫一遍 Hacker News，按我平时的口味分好类推过来，一周攒下的阅读清单从没断过更。几个政务网站的公开栏目一有更新，飞书立刻响。定时任务这件事，说大不大，但它是"替你值班"和"你问它答"的分界线。

## 为什么不喂给大厂

有人会问：订阅费也不贵，何必自己折腾？

前两天一份 AI 产品尸检报告给了答案：三年下来，440 多个 AI 产品关停下线。腾讯元器停服，一批把知识库和自动回复搭在上面的公众号博主一夜失效；更早些时候，几家大厂集中下线了 800 万个用户自建的智能体。那一周，自托管玩家的 Agent 该干嘛干嘛，毫发无损。

开源也不保险，这我承认——出 bug 一样坑你。但开源不是保险箱，是玻璃箱：坏了，你看得见哪里坏；气不过，能自己改；实在不行，整体搬家。大厂的产品呢？数据能不能导出、给几天窗口期，都得看它心情。

真正值钱的还不是"开源"两个字，是数据躺在标准格式里：笔记是 Markdown，配置在 git 里，规则是一份 AGENTS.md 纯文本。哪天这个项目不维护了，换一个 Agent 来接管这些文件就是。数据不锁死，才是底气的来源。

## 写在最后

苏轼讲过八个字："博观而约取，厚积而薄发。" 我的 Agent 越来越懂我，没什么玄学——记忆是存量，工作流是复利，半年攒下来而已。这份"懂"没法转让，也没法被收走，因为它长在我自己的机器上。

前两篇文章说，Agent 兜兜转转回到了原点，竞赛的终点是内核不是入口。这一篇算是把圆画回了家里：原点是圆心，内核是半径，而画圆的图纸，不用按月付费。

大厂忙着给 Agent 配钥匙扣的时候，你完全可以自己搭一个。钥匙扣会过时，账单会到期——自己搭的东西，谁也收不走。
