# NeoPad 写完了

> 全文约 2400 字。

我有一个不太好的习惯：想到什么先记在聊天窗口里。跟 AI 对话时冒出一个思路，随手敲进去；开会时突然想到一件待办，开个空对话框打几个字；看网页遇到一段值得留意的文字，复制粘贴到某个完全不相干的聊天记录里。

过几天想找——翻半天找不到。因为记的时候就没想过要"放"在哪里。

这种情况太多了。不是每条信息都值得打开 Obsidian，新建一个笔记，想标题，选目录，打标签。有些东西就是需要先记下来，三秒钟之内，然后继续干手头的事。

NeoPad 就是为这种时刻做的。

## 不是知识库，是桌面边上的便签纸

现在的笔记软件一个比一个全能。双向链接、数据库视图、知识图谱、云端同步、AI 问答、模板引擎——功能越来越完整，启动成本也越来越高。

当你只想记一句话的时候，拦住你的通常不是功能不够，而是一连串琐碎的决策：该放哪个目录？该打什么标签？这个算临时笔记还是正式条目？

NeoPad 不碰这些问题。它不做知识库，不搞分类体系，不试图替代 Obsidian 或 Notion。它就是一张贴在桌面边上的便签纸——需要时弹出来，写完自动保存，关掉也不退出，下次叫它还秒开。

适合往里面塞的东西包括：会议要点、临时待办、代码思路、剪贴板里复制来的片段、当天速记、AI 对话里值得留下一句话。

你不需要想清楚它属于哪里。先记下来再说。

## 数据就在硬盘上，不锁在数据库里

NeoPad 所有笔记都是 Markdown 文件，默认放在 `~/.neopad/notes/`。

没有私有数据库格式，没有云端锁定。哪天不想用了，随便用什么文本编辑器都能打开。配置、标签页、提醒状态也都是本地文件。删除笔记时不会直接删，先挪到 `trash/`。

这些设计听着不起眼，但对于一个常驻桌面、天天往里塞东西的小工具来说，数据不丢失、可恢复、随时带得走，比花哨的功能重要得多。

## 打开，输入，走人

日常用法就三个动作：呼出窗口，打字，离开。自动保存处理剩下的事。

支持多标签页，你可以按用途分开：默认页放当天杂记，剪贴板页收集复制来的资料，项目页记录某个开发任务的上下文，会议页记待办和结论。全局快捷键可以随时显示或隐藏窗口。关闭窗口只是藏到后台，不是退出，下次用的时候再叫出来。

还有一个我蛮喜欢的细节：可以把当前剪贴板内容快速追加到固定页面。很多临时资料不是马上要整理，但又不能丢。扔进一个可搜索的 Markdown 页面，比散落在浏览器标签、聊天窗口和剪贴板历史里靠谱多了。

## Markdown 预览，但不过度

编辑器提供三种模式：纯编辑、左编辑右预览、纯预览。按 `F4` 切换，短记录用编辑模式就够了，稍长一点的清单或说明切到混合模式更舒服。

0.4.4 版本加了多套预览主题——Light、One Dark、Nord、Solarized、Monokai、GitHub Light、Dracula。不是换个背景色完事，而是对标题、链接、引用、代码块、表格做了整体适配。`F7` 循环切换预览主题，`F9` 切换应用本身的明暗模式，"内容风格"和"界面明暗"是分开的两件事。

字体设置也改了。早期版本要手动填 CSS 字体串，对不写代码的人很不友好。现在有专门的弹窗，预设了 JetBrains Mono、SF Mono、Menlo、Consolas 等常见字体，滑块调字号，下面实时预览效果。功能可以专业，但操作不应该把复杂性甩给用户。

## 待办直接写在 Markdown 里

NeoPad 支持一种轻量提醒，写法是这样的：

```text
- [ ] @remind 2026-07-10 09:30 跟进某件事
```

没有引入独立的任务管理系统，提醒仍然是一行 Markdown。完成的时候 NeoPad 会把复选框勾上，原文还在。待办既能被提醒，又不脱离笔记正文。

`Ctrl+E` 插入提醒，`F5` 打开提醒列表查看待处理和已到期的事项。

## 给键盘和 Vim 用户留了路

常用快捷键都绑好了：`F2` 重命名页面、`F4` 切换编辑模式、`F5` 提醒列表、`F8` 设置、`F11` 沉浸式全屏、`Ctrl+Tab` 切标签页。

如果你用 Vim，NeoPad 有可选的 Vim 编辑模式，状态栏显示当前是 Normal、Insert 还是 Visual。不是为了在便签工具里复刻 Vim，而是让已经形成肌肉记忆的人不用频繁切换思维。

对一个"随手记"的工具来说，手不用离开键盘，就是效率。

## 本地 MCP：让 AI Agent 能读写笔记

NeoPad 内置了一个本地 MCP 服务。支持 MCP 的本地 AI Agent 可以在授权后读取、搜索、写入 NeoPad 笔记。比如让 Agent 把整理好的内容追加到某个页面，或者从笔记里搜之前记录的上下文。

这个功能默认关闭，需要手动启用。访问要 bearer token，还会校验来源。NeoPad 没有在应用里塞一个 AI 聊天窗口——它把自己做好成一个可靠的记录工具，再通过清晰的接口让外部 Agent 接入。

笔记工具仍然是笔记工具，Agent 只是被授权的协作者。这个分寸感我觉得是对的。

## 说白了吧

NeoPad 不打算做功能最多的笔记软件。它做的事很小：让你想到什么的时候，三秒之内记下来；需要的时候，搜得到；不想整理，也不用担心丢了。

它是本地的，数据是你的。它轻量，但 Markdown 预览、多标签、快捷键、提醒、Vim 模式、MCP 接口这些该有的都有。它有明确的边界——团队协作、云端同步、项目管理、长篇排版，这些它不做。一个小工具最怕的事情就是失去边界。

NeoPad 已经开源了。如果你也经常有一些来不及分类、但又不想丢掉的想法，也许值得试试。

欢迎提 issue。bug、体验问题、功能建议、"某个细节不够顺手"，都可以说。一个小工具能不能长期好用，往往取决于这些日常使用里的细微感受。
