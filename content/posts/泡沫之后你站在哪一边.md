# 泡沫之后，你站在哪一边？

王煜全老师最近一场访谈，两个小时，几乎每二十分钟推翻一个共识。

他学生物出身，给中国移动当过很多年顾问，看了二十几年科技产业。这一场，从工业革命聊到登月，从达尔文聊到刘邦，最后落脚到一个很多人不敢讲的问题——

**AI 泡沫，很可能在 2029 年破灭。**

但泡沫本身不是重点。重点是泡沫之后，世界长什么样，你站在哪一边。

## 「这次不一样」——每次泡沫前都这么说

技术革命从来不走直线。

回头看，铁路泡沫、互联网泡沫、比特币泡沫，剧情大同小异：一项新技术出现，先是没人看得上，然后有人尝到甜头，接着所有人都冲进去，估值飞上天，最后预期兑现不了，砰的一声。

互联网泡沫 2000 年破裂的时候，纳斯达克从 5000 多点跌到 1100 点，无数公司灰飞烟灭。但活下来的亚马逊、谷歌，后来各自涨了几十倍。泡沫的真正功能不是毁灭——是筛选。投机者被洗出去，真正创造价值的东西反而被低估，然后进入下一个增长周期。

AI 这波也不会例外。王煜全的判断是：2028 年左右预期被推到顶，2029 年落下来。大众看清了 AI 的好处，又发现收益没有想象中来得那么快，落差一来，恐慌随之而来。

拿现在的数据看，其实已经有苗头了。OpenAI 一季度亏了 115 亿美元，预计要到 2030 年才能转正。大型科技公司到 2028 年将投入约 3 万亿美元搞 AI 基建，而 AI 的年收入目前只有 500 亿左右——摩根大通算过，要 10% 的回报率，年收入得涨到 6500 亿，是现在的十三倍。

投资人不是看不到这些数字。但此刻谁也不敢先退——用扎克伯格的话说，"哪怕最后在 AI 上花了几千亿美元，错失机会的风险更高。"这就是典型的泡沫心态：我知道它贵了，但我更怕踏空。

泡沫迟早会来。它不是坏事。泡沫意味着资本冷静下来了，市场开始问"你到底能不能赚钱"而不是"你的 PPT 够不够酷"。真正好公司脱颖而出的时刻，恰恰是泡沫破裂之后。

问题是——泡沫是筛子，不是墓碑。关键在于，你是被筛掉的，还是筛完之后还站在场上的那个。

## 刘邦不会打仗

访谈里有一个观点让我想了很久：AI 革命不是在取代某一个岗位，而是在吃掉所有能被流程化的脑力劳动。

以前我们觉得，AI 顶多帮你写写邮件、做个 PPT。但现在 Agent 的发展速度远超预期——从搜集资料、写脚本、剪视频，到代码调试、数据分析、客户跟进，一条完整的业务链条，AI 能从头跑到尾。

王煜全说了一句很直白的话：**"最好的公司，是 Agent 很勤奋，人在旁边睡觉。"**

听着像段子，逻辑却很硬。工业革命的时候，瓦特发明蒸汽机当然关键，但真正改变世界的，是阿克莱特建起的工厂体系——把动力从"偶尔能用"变成"连续可用"，把生产从"靠手艺"变成"靠流程"。AI Agent 就是这套新流程。每一个环节被拆解、被自动化、被 AI 接管。组织运转的核心不再是"人加班加得够不够狠"，而是"Agent 链路设计得够不够好"。

那人在干嘛？在选、在判、在验。

我自己日常用 AI Agent 处理信息——整理笔记、跑调研任务、监控网页变化、写公众号的选题分析。越用越明显地感受到一件事：我干的活正在从"执行"变成"审核和纠偏"。我不再一条条搜资料，而是检查 Agent 找回来的东西对不对、全不全、有没有幻觉。我不再从头写初稿，而是拿着草稿改——改观点、改语气、补上 AI 永远不会知道的那些个人经历和真实细节。这个过程不算轻松，但确实和以前完全不一样了。

《史记·高祖本纪》里有一段刘邦自己的总结，大意是：运筹帷幄，我不如张良；带兵打仗，不如韩信；管后勤搞经济，不如萧何。这三个人都是人杰，我能用他们，所以我赢了天下。

刘邦不会打仗，但他会选人、会判断、会在关键节点拍板。两千年前的道理，放到 AI Agent 时代，依然成立。

未来的核心竞争力，不是你能不能把某一件具体的事做得比别人好——这件事 Agent 早晚比你做得更好。而是你能不能在 Agent 跑起来的过程中，做出好的判断、发现它犯的错、指出它没想到的方向。

王煜全把话说得更白：教育系统应该从教人"打枪"转向教人"当元帅"。这话听着刺耳，但仔细想想，你身边有多少人的日常工作说白了就是"打枪"——执行别人定的目标、按别人设计的流程、产出别人要的结果？这部分工作，Agent 可以做得更快、更便宜、更不出错。

留给你的是那些 Agent 做不了的事：判断对错、选择方向、定义什么是"好"。

说白了，从"打枪的"变成"当元帅的"。

## 写在最后

泡沫会来。Agent 会来。

这两件事，大概在接下来三五年内都会发生。有人在恐慌中离场，有人在泡沫破裂后捡到被低估的机会——就像 2000 年之后买入亚马逊的人一样。

但比预测泡沫更现实的问题是：**当 Agent 能做你手里 80% 的活，剩下那 20%，你接得住吗？**

想清楚这件事的人，泡沫来了反而是入场信号。
