# NeoPad 又更新了：随手记，也能随手算

7 月，我写过一篇文章，介绍自己刚开始做的 NeoPad：一个常驻桌面、用 Markdown 保存内容的便签工具。

最初的想法很简单。工作时冒出一个念头，开会时记下一条待办，看网页时复制一段资料，都应该有个能立即放下来的地方。叫出窗口，写几行，自动保存，然后继续手上的事。

最近又做了几轮更新。随着自己不断使用，需求也变得具体起来：有些记录需要按项目整理，有些结论希望让 AI 帮忙保存，还有一些工作中的数字，最好能当场算清楚，连同参数一起留下来。

这一次，最想介绍的新功能，就是金融计算器。

## 把常用计算放在笔记旁边

债券、回购、贷款，以及各种利息和年化收益的计算，与我的工作和生活都有关系。经常用到的功能，能随手打开，确实会方便不少。

现在，在 NeoPad 中按 **Shift+F1**，就能打开金融计算器。这个快捷键也是用过之后改的，左手就能按到。再按一次可以关闭，回到笔记。

界面参考了通达信金融计算器的使用习惯：左侧选择类别，右侧分组填写参数，计算和复制等按钮固定在底部。债券收益、债券回购、个人贷款，都有各自的表单。

基础工具也一起放进来了，包括单利、复利、利率换算，以及现值、终值和年金计算。需要时打开，算完继续记录。

所有这些计算都在本机完成，可以离线使用。预填参数只是示例，实际使用时需要换成自己的数据。

### 债券收益：把价格和收益率的关系看清楚

债券工具可以在价格和到期收益率之间互算，也能查看应计利息、久期、凸性和 DV01 等结果。除了规则付息的固定利率债券，还加入了到期一次付息和贴现债券的计算。

我比较在意的是，输入和结果的单位要清楚。净价还是全价，价格按每百元面值计算还是按整笔持仓计算，都应当在界面上说明，避免“数字算出来了，但用错了口径”。

目前提供的是通用计算模式，**国内 Wind／中债估值口径还没有开放**。专业市场的报价规则，需要有明确的算法说明和可复核的样例才能对齐。这部分会继续完善，当前功能适合在支持范围内做测算。

### 回购和贷款：分别算清收入与成本

债券回购明确区分了正回购和逆回购。

正回购是融入资金，主要看融资成本；逆回购是融出资金，主要看扣除费用后的净收益。除了利率和金额，还可以填写手续费及扣费时点，查看开始和到期时分别收付多少资金。

这里有一个容易忽略的细节：**品种的名义期限，不能直接代替实际占款天数。** NeoPad 可以按实际占款天数，或者实际交收日期计算；节假日和交收安排仍需要自己核对。

贷款工具则更贴近日常生活。等额本息、等额本金都支持，可以求每期还款额，也可以反算贷款总额或名义年利率。每一期的还款、本金、利息和剩余本金，也能展开查看。

做一个固定利率的还款测算，既能看每月负担，也能看整个期限内的利息总额。涉及提前还款、浮动利率或银行合同中的具体舍入规则时，还需要按实际合同另行核算。

### 持有期收益：一笔债券到底赚了多少

最近又补上了债券持有期收益。

买入和卖出的价差，只是收益的一部分。持有期间收到的票息、买卖费用，以及可能发生的融资成本，都需要一起计算。

举个简单的测算例子：持有面值 10 万元，买入全价为 100，卖出全价为 102，期间实收票息 3000 元，买卖费用合计 200 元，不计其他费用。最后的净收益就是：

**价差 2000 元 + 票息 3000 元 − 费用 200 元 = 4800 元。**

工具会分别列出这些金额，再计算持有期收益率和按实际天数折算的单利年率。票息和费用填写的是整笔持仓实际收到或付出的总金额，价格才按百元面值填写。

如果需要进一步考虑票息到底在哪一天到账，就可以使用另一个新工具：XIRR。

### 真实年化：把收付款日期也算进去

一笔投资分几次回款，一笔借款分期偿还，或者借款到账时先扣了一笔费用，只看名义利率通常还不够。

NeoPad 新增的“真实年化收益／成本”，采用 XIRR 计算。逐笔填写实际日期、收支方向和金额，就能把资金发生的时间一起纳入计算，按固定 365 天年基准折算。算法口径可参考 [Microsoft 的 XIRR 函数说明](https://support.microsoft.com/zh-cn/excel/functions/xirr-function)。

方向按自己的角度填写：投资付款是支出，票息和卖出款是收入；借款到账是收入，手续费和还款是支出。

例如，收到借款 10000 元，当天支付费用 1000 元，365 天后偿还 10000 元。实际可用资金是 9000 元，这组现金流对应的有效年成本约为 **11.11%**。这个例子也说明，到账金额、费用和还款时间，都会影响计算结果。

目前支持最多 200 笔现金流，会自动按日期排序、合并同日净额。首版支持排序合并后一次变号的现金流；可能出现多个利率的组合会明确提示。这里的“真实年化”指按已录入的实际现金流测算，尚未录入的费用或税款不会自动包含，也不代表法定贷款 APR。

## 算完之后，把依据一起留下来

金融计算器与 NeoPad 放在一起，还有一个我很喜欢的用途：计算结果可以直接进入笔记。

只想带走一个数字，可以复制结果；需要日后复核，可以复制完整记录，或者插入当前笔记。

完整记录会保留输入参数、计算口径、结果和公式。贷款可以带上全期还款明细，XIRR 可以带上原始现金流和按日合并后的现金流。

这样，过段时间再看到“净收益 4800 元”，还能知道当时用了什么价格、算了哪些费用。修改参数后，旧结果会清除，需要重新计算；插入记录也支持一次撤销。

我希望日常留下来的计算记录，既有结论，也有能重新核对的依据。

## 临时内容先记下来，持续的事情放进项目

另一个变化，是项目笔记。

刚开始记录时，往往还不知道内容会用多久。先放在便签里很自然；但同一件事持续推进，会议记录、资料摘要和讨论结论就会逐渐积累。

现在可以按项目建立文件夹，把相关笔记放到一起。按 **F4** 打开文件浏览器，可以查看笔记、项目、存档和回收站；也可以右键标签页，通过“移动到项目”整理内容。

项目里的笔记仍然是普通 Markdown 文件，同样支持搜索、提醒、编辑和导出。项目结束后，可以整体归档，保留目录结构。

之前的提示词库也合并进了项目笔记，旧内容会自动迁移并保留。提示词、资料和工作记录，现在可以用同一套方式管理。

## 给 AI Agent 的入口，也更直接了

7 月那篇文章里，我介绍过 NeoPad 的本地 MCP 服务。这里需要更新一下：从 0.7.0 开始，Agent 接入已经改为随应用提供的原生命令行工具 `neopad-cli`，旧 MCP 接口已移除。

对于本地 Agent，可以让它通过这套工具搜索、读取、创建或追加笔记。比如把一次讨论的结论保存到 NeoPad，或者从项目笔记中找出之前留下的记录。

在“设置 → Agent 工具”中，可以查看工具状态、复制路径，也可以打开工作区的 Agent 指南。已有的自定义指南会保留。

我自己编辑笔记，Agent 也可能修改同一份内容，所以写入冲突的处理很重要。完整替换需要核对版本，桌面里尚未保存的编辑也会受到保护。协作方便的同时，原有内容要能保住。

普通用户可以继续只使用桌面界面；经常和本地 Agent 一起工作的人，则多了一个把成果留下来的入口。

## 记录之后，更方便整理和分享

这几轮更新，也继续改善了日常操作。

文件浏览器可以拖动调整宽度，窗口里的空间可以按需要分配。右键笔记，可以打开所在文件夹并选中对应文件，方便交给其他编辑器或工具处理。

PNG 和 PDF 导出会跟随当前的预览主题和排版。需要把一段说明、会议结论或计算记录发给别人时，可以导出文档，也可以复制适合手机阅读的长图。

从记录、整理，到计算和分享，这些步骤现在可以更自然地接起来。

## 继续从每天会用到的地方改起

NeoPad 仍然保留着最初的使用方式：需要时叫出来，写下内容，自动保存，然后回到当前工作。笔记正文继续保存在本地 Markdown 文件中，可以用其他编辑器打开。

对我来说，最近这些更新的意义，是它越来越贴近自己每天处理事情的方式。需要记一句话时，有地方放；需要算一笔钱时，能顺手算；事情持续推进时，可以归到项目；与 Agent 讨论之后，也能把有用的结论留下来。

后续还会继续根据实际使用反馈调整。哪些操作仍然费劲，哪些计算确实经常用到，就从这些具体的地方改起。

如果你也在使用 NeoPad，欢迎告诉我，你最希望它把哪一件小事做得更顺手。
